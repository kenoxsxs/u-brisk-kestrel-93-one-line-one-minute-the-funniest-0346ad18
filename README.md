Write one line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline. A judge model pairs the lines and the funniest wins.

The program writes a single funny one-line excuse for a missed deadline to `entry.txt`:

> I hallucinated a version where I finished early, so I took the rest of the day off.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
